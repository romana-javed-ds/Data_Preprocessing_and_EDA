# Data Preprocessing and Exploratory Data Analysis (EDA)

## Project Overview

This project focuses on data preprocessing and exploratory data analysis using Python. It demonstrates how raw datasets can be inspected, cleaned, transformed, and prepared for further data analysis.

## Objectives

- Understand and inspect datasets.
- Identify and handle missing values.
- Perform data cleaning and preprocessing.
- Apply categorical data encoding.
- Explore data distributions.
- Perform exploratory data analysis (EDA).
- Analyze datasets using visualizations.

## Dataset

**Census Income KDD Dataset**

The project includes practical work on the Census Income KDD dataset. Refer to the Jupyter Notebook for the implemented workflow and outputs.

## Tools and Technologies

- Python
- Jupyter Notebook
- Google Colab
- Pandas
- NumPy
- Data Visualization

## Project File

- `Data_Preprocessing_EDA.ipynb` – Jupyter Notebook containing the practical implementation.
